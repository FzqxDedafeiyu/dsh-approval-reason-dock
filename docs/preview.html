Settings · two switches (default on)
Approval Note Dock
Controls "allow with note" and "allow confirmation". Reject with a note always works and is not affected by these switches.
Allow with note
Attach a note when allowing; it enters the running turn as a steering user message.
On: the note becomes a normal user message in the session log and model context; if it cannot be delivered, the approval is not answered (retryable).
Off: allows carry no conditions — the model only sees a native allow; use "Reject with note" instead.
Allow confirmation
Clicking allow opens an in-panel confirmation before the tool call runs.
On: one extra step per allow; frequent approvals feel slower.
Off: clicking allow runs the tool call immediately; no second line of defense against misclicks.
Both default to on; stored in this browser.
